# 🖥️ App Gráfica de Chat

## Inicio rápido

```bash
./start_gui.sh
```

## Características

- ✅ Interfaz minimalista y limpia
- ✅ Sin servidor localhost
- ✅ Historial persistente
- ✅ Soporte para atajos (Enter para enviar, Shift+Enter para nueva línea)
- ✅ Menú de archivo con opciones

## Características

- **Negrita**: Título y nombres de roles
- **Colores**: Verde para usuario, Azul para asistente
- **Scroll automático**

## Comandos de teclado

- `Enter` - Enviar mensaje
- `Shift+Enter` - Nueva línea
- `Ctrl+Q` - Salir

## Menú Archivo

- **Limpiar chat** - Borra el historial actual
- **Salir** - Cierra la aplicación
